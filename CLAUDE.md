# AGENTS.md

This file holds the durable rules for this project. Topic guides in `docs/agents/` hold the rest.

## Project rules

- Keep this file limited to durable project decisions. Do not repeat global instructions, code-derived facts, version details, or incident history.
- Follow the existing directory structure. Store assets with similar assets. Do not add output folders, galleries, reports, or duplicate guides unless requested. Remove temporary work after use.
- Preserve the established portrait, typography, and palette when you polish the site. Keep block details subtle in the interface and more expressive in article covers.

## Topic guides

Read the guide for a topic before you work on it.

- [`docs/agents/tooling.md`](docs/agents/tooling.md): run, build, test, lint, or deploy the site.
- [`docs/agents/cloudflare.md`](docs/agents/cloudflare.md): change `cloudflare.config.ts`, bindings, previews, builds, or deploys.
- [`docs/agents/emdash.md`](docs/agents/emdash.md): change EmDash config, content, media, or the admin.
- [`docs/agents/article-covers.md`](docs/agents/article-covers.md): create or replace an article cover.
