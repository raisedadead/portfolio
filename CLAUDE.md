# AGENTS.md

## Project rules

- Keep this file limited to durable project decisions. Do not repeat global instructions, code-derived facts, version details, or incident history.
- Follow the existing directory structure. Store assets with similar assets. Do not add output folders, galleries, reports, or duplicate guides unless requested. Remove temporary work after use.
- Preserve the established portrait, typography, and palette when polishing the site. Keep block details subtle in the interface and more expressive in article covers.
- For cover updates, preserve article bodies, inline images, metadata, and unrelated unpublished edits. Leave freeCodeCamp covers unchanged unless explicitly requested.

## Article covers

Reuse the same **style, palette, camera, and lighting**, then change the subject for each article.

For future requests, you can say:

> Create a cover for “[article title]” using my existing brick-built article-cover style. Read the saved manifest and use an existing cover as a visual reference. Base the scene on this article: [summary or content].

The reusable style recipe is:

```text
16:9 editorial cover. Isometric 3D voxel diorama inspired
by Minecraft and interlocking LEGO bricks.

Crisp stepped shapes, subtle studs, matte surfaces.
Pale mint, teal, peach-orange, ivory, and charcoal.
Mint-to-ivory backdrop, warm upper-left light, soft shadows.
Front three-quarter orthographic view.

One clear visual metaphor for the article.
Generous margins for cropping; readable at thumbnail size.
No text, watermarks, or unrelated logos.

Subject: [describe the scene here]
```

Choose a concrete metaphor: **DNS → connected server islands; caching → storage drawers; filtering → a sorting gate**.

Review the result at thumbnail size, export as **1280 × 720 WebP**, add descriptive alt text, and replace only the cover field in EmDash. Keep the prompt alongside the image so you can reproduce the direction later.
