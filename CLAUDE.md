# AGENTS.md

This file holds the durable rules for this project. Before you work on a topic, read its guide in `docs/agents/`.

## Rules

- Keep this file to durable project decisions. Put topic detail in a guide in `docs/agents/`.
- Do not repeat global instructions, code-derived facts, version details, or incident history.
- Follow the existing directory structure. Store an asset with similar assets.
- Do not add output folders, galleries, reports, or duplicate guides unless the operator asks.
- Remove temporary work after use.
- When you polish the site, keep the portrait, typography, and palette.
- Keep block details subtle in the interface and more expressive in article covers.

## Topic guides

- [Tooling](docs/agents/tooling.md): run, build, test, lint, or deploy the site.
- [Cloudflare](docs/agents/cloudflare.md): change `cloudflare.config.ts`, bindings, previews, builds, or deploys.
- [EmDash](docs/agents/emdash.md): change EmDash config, content, media, or the admin.
- [Article covers](docs/agents/article-covers.md): create or replace an article cover.
